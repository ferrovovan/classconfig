# Changelog

Все значимые изменения документируются в этом файле.
Формат основан на [Keep a Changelog](https://keepachangelog.com/), проект придерживается [Semantic Versioning](https://semver.org/).

## [1.0.0] — 2026-11-01

Первый релиз ClassConfig.

### Ядро (CLI)

- Команды `snapshot` и `check`: атомарный эталонный снимок плоской папки текстовых
  конфигураций и сравнение с ним с пофайловой классификацией статусов
  (изменён / добавлен / удалён / без изменений).
- Манифест эталона `manifest.json` с SHA-256 контрольными суммами, проверка целостности.
- Автономный HTML-отчёт различий «Было — Стало»: встроенный CSS, экранирование,
  сжатие длинных совпадающих участков, открытие по `file://` без интернета.
- Только стандартная библиотека Python 3.10+ (0 зависимостей), 17 кодов ошибок,
  CI/CD-дружелюбные коды возврата 0/1/2.

### Веб-демо (`web/`)

- SPA на React 19 + Vite + Tailwind CSS с клиентским движком, воспроизводящим CLI 1:1
  прямо в браузере; полностью статичная сборка публикуется на GitHub Pages.
- Вкладки: пошаговый демонстрационный сценарий, виртуальная файловая папка,
  эмулятор терминала, просмотрщик HTML-отчёта, браузерный прогон 20 приёмочных
  тестов, конструктор руководства пользователя с markdown-предпросмотром.

### MCP-сервер (`mcp/`)

- Model Context Protocol (JSON-RPC 2.0, protocolVersion 2025-06-18) с двумя
  стандартными транспортами: `stdio` (`python3 -m mcp`) и Streamable HTTP
  (`python3 -m mcp --transport http`).
- Пять инструментов: snapshot, check, validate, generate_guide, get_limits.
  Манифест `mcp/mcp.json` генерируется из единого реестра инструментов.

### Тесты и CI

- 20 приёмочных тестов CLI (unittest), тесты MCP-развёртывания, 22 юнит-теста
  клиентского движка демо (node:test).
- GitHub Actions: тесты Python 3.10/3.11/3.12, линт и сборка демо, автодеплой на Pages.
